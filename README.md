# 【Java｜JavaSE】Java近期练习集 - 面向对象综合实战

本项目基于 Java SE 技术栈搭建，收录近期 Java 练习合集，模块化组织便于回顾。

## 核心能力
- Scanner 输入、运算符与类型转换
- 数组与二维数组操作
- static 静态成员、JavaBean 规范
- 电影分享综合小项目

## 技术组成
- JDK / Java SE
- 纯 Java 控制台程序

## 目录结构
- bask.code / begin：基础输入、字面量、运算符
- day04 / day05：数组、二维数组、综合练习
- OOP：JavaBean、静态成员、this、封装、电影分享项目
